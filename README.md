## What I've Built

### Nature Nook — Full-Stack E-Commerce Platform
Production e-commerce platform for a herbal and nutraceutical business, built from scratch.

**Next.js (App Router) · React 19 · TypeScript · PostgreSQL · Prisma ORM · Zustand · Razorpay · Tailwind CSS · shadcn/ui · Cloudinary · Resend**

- Architected the full storefront from zero — product listings, cart, checkout, order lifecycle, transactional emails
- Integrated Razorpay with server-side HMAC-SHA256 signature verification to prevent payment spoofing
- Migrated database from SQLite to production PostgreSQL on Railway via Prisma — type-safe schema management
- Built persistent cart state with Zustand synced to localStorage; instant fuzzy search via Fuse.js
- Automated Google Merchant Center sync via a dynamic XML RSS feed endpoint
- In-memory caching layer on external API calls to protect rate limits under load

### Pinsights — Fashion Intelligence System
Multi-agent RAG pipeline that analyses image collections to produce aesthetic identity profiles and gap analysis.

**LangGraph · CLIP · HDBSCAN · Qdrant · Groq (Llama 3) · Python**

- Three autonomous agents — Identity, Gap, Narrator — orchestrated via LangGraph
- CLIP embeddings clustered with HDBSCAN, retrieved against dual Qdrant collections, synthesised into structured insight cards
- Teacher–Student active learning roadmap: LLM-generated JSON labels used to progressively train a lightweight student model, reducing inference cost without sacrificing accuracy

### Real-Time Polygon Netflow Model
Full-stack blockchain data indexer tracking native POL token transfers in real time.

**FastAPI · Streamlit · SQLite · Web3 · Python**

- Calculates live inflow/outflow across 6 known Binance addresses
- Full stack: CLI · FastAPI endpoints · Streamlit dashboard
- Normalised SQLite schema architected for ERC-20 expansion
